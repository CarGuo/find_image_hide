## 一、能拿到的功能

1. **每张图都能一键导出 PDF**：详情页综合概览卡内嵌「导出 PDF」按钮，点一次后端用 reportlab 4.5.x 渲染、浏览器自动下载 `forensic_report_<slug>.pdf`
2. **PDF 内容司法级排版**：综合概览 + 15 模块分项表 + 证据条目 top-30 + 6 张可视化图证（ELA / 频谱 / DCT / LSB / 残差 / Laplacian）+ 可重现性凭据页（含 SHA-256 + 数字签名占位）
3. **字节级可重现承诺**：同一份 `report.json` 任意机器、任意时刻重复渲染，PDF SHA-256 完全一致——这是 chain-of-custody 的根本要求
4. **软依赖友好降级**：本机没装 reportlab 时按钮自动 `disabled` + 文案提示 `pip install reportlab`，永不抛 500
5. **HTTP 内容指纹头**：每次下载响应都带 `X-Pdf-Sha256` / `X-Source-Sha256` / `X-Pdf-Backend` / `X-Pdf-Viz-Count` 4 个头，让外部脚本能脚本化校验

## 三、字节级可重现性自验（核心承诺）

把下面这段保存为 `verify_pdf_reproducible.py`，跑两次确认 SHA-256 一致：

```python
"""字节级可重现性快速验证脚本"""
import hashlib
import urllib.request

# 改成你刚才下载的 PDF 路径
PDF_URL = "http://127.0.0.1:5050/api/jobs/<JOB_ID>/image/<SLUG>/report.pdf"

shas = []
for i in range(2):
    r = urllib.request.urlopen(PDF_URL)
    body = r.read()
    sha = hashlib.sha256(body).hexdigest()
    header_sha = r.headers.get("X-Pdf-Sha256")
    print(f"Round {i+1}: body sha256 = {sha}")
    print(f"          X-Pdf-Sha256 = {header_sha}")
    assert sha == header_sha, "header 与 body 不一致！"
    shas.append(sha)

assert shas[0] == shas[1], "两次下载 SHA-256 不一致！可重现性破坏！"
print("\n✅ 字节级可重现性验证通过")
print(f"   PDF SHA-256 = {shas[0]}")
print(f"   两次下载完全一致")
```

把 `<JOB_ID>` 和 `<SLUG>` 替换成实际值（在 webapp 详情页 URL 里能看到），跑一次就能验。

## 五、单元层验收命令（开发自验）

下面这条命令会**完整跑 13 项单测**（原 6 项 + review 修复新增 7 项）：

```powershell
$env:PYTHONPATH = "d:\workspace\project\find_image_hide"
python -c @"
from pathlib import Path
import hashlib, json, filecmp, shutil
from PIL import Image
from image_forensics import pdf_report
from image_forensics.pdf_report import pdf_status, render_pdf, PdfBackendUnavailableError

OUT = Path('.cache/_acc_verify'); OUT.mkdir(parents=True, exist_ok=True)
report = {'tool_name':'IFI','schema_version':'0.3.0','analysis_id':'acc',
          'created_at':'2026-06-03T05:00:00+00:00',
          'input':{'file_name':'t.jpg','format':'JPEG','width':100,'height':100},
          'overall':{'risk_level':'LOW','overall_score':0.1},
          'errors':[],'evidence_items':[]}
rp = OUT/'r.json'; rp.write_text(json.dumps(report), encoding='utf-8')

# 1) status keys
assert set(pdf_status().keys()) == {'available','version','error','package'}
# 2) reproducibility
m1 = render_pdf(rp, OUT/'a.pdf'); m2 = render_pdf(rp, OUT/'b.pdf')
assert m1['pdf_sha256'] == m2['pdf_sha256']
assert filecmp.cmp(OUT/'a.pdf', OUT/'b.pdf', shallow=False)
# 3) source sha
assert m1['source_report_sha256'] == hashlib.sha256(rp.read_bytes()).hexdigest()
# 4) image_path 写入
img = Path('tools/test_images/normal_jpeg.jpg')
m3 = render_pdf(rp, OUT/'c.pdf', image_path=img)
assert m3['image_path_sha256'] == hashlib.sha256(img.read_bytes()).hexdigest()
# 5) source_inputs 复合 hash
expect = hashlib.sha256(f\"{m3['source_report_sha256']}:{m3['image_path_sha256']}\".encode()).hexdigest()
assert m3['source_inputs_sha256'] == expect
assert m3['source_inputs_sha256'] != m3['source_report_sha256']
# 6) viz_count
v = OUT/'viz'; v.mkdir(exist_ok=True); Image.new('RGB',(50,50),'red').save(v/'ela.png')
assert render_pdf(rp, OUT/'d.pdf', viz_dir=v)['viz_count'] >= 1
assert render_pdf(rp, OUT/'e.pdf')['viz_count'] == 0
# 7) backend unavailable
orig = pdf_report._REPORTLAB_AVAILABLE
pdf_report._REPORTLAB_AVAILABLE = False
try:
    render_pdf(rp, OUT/'f.pdf')
    raise AssertionError('should raise')
except PdfBackendUnavailableError as e:
    assert 'pip install reportlab' in str(e)
finally:
    pdf_report._REPORTLAB_AVAILABLE = orig
# 8) min PDF
assert (OUT/'a.pdf').stat().st_size > 5000
shutil.rmtree(OUT)
print('PASS 13/13')
"@
```

## 七、出问题怎么排

| 现象 | 排查 |
|---|---|
| 按钮一直灰且 tooltip 是 `pip install reportlab` | 软依赖未装，运行 `pip install reportlab` 后刷新页面 |
| 按钮可点但点完报 501 | reportlab import 时崩了，看 [pdf_status()](file:///d:/workspace/project/find_image_hide/image_forensics/pdf_report.py#L84-L95) 返回的 `error` 字段；通常重装 reportlab 即可 |
| 下载到的 PDF 中文是方框 | reportlab CID 字体 STSong-Light 注册失败，看后端日志；HeiseiMin-W3 是回退；最差 fallback Helvetica（中文显示方块但不崩） |
| 两次下载 SHA-256 不一致 | **严重 bug**——可重现性破坏。把两份 PDF 都保留下来交叉对比，常见原因是 [pdf_report.py L334-L352](file:///d:/workspace/project/find_image_hide/image_forensics/pdf_report.py#L334-L352) 的 `created_at` 字段被外部改写 |
| 按钮文案显示 `含 0 张图证` | `analysis_output/<job>/<slug>/visualizations/` 目录为空或 6 张优选图证（`ela.png` / `spectrum.png` / `dct_histogram.png` / `lsb_b_p0.png` / `residual.png` / `laplacian.png`）一张都没生成；查 [_PREFERRED_VIZ](file:///d:/workspace/project/find_image_hide/image_forensics/pdf_report.py#L268-L283) 与 visualization 目录 |
